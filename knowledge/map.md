## 阶段零：底层原理（必修，按顺序）

### [ ] L1 电压、电流、电阻
- 电压是两点之间的压差，电流是每秒流过的电荷量，电阻是阻碍
- 欧姆定律：电流 = 电压 ÷ 电阻
- 电流必须走闭合回路，断一处就是零
- 短路：电阻接近零，电流只受电池内阻限制
- 类比：水压、流量、水管粗细
- 检验题：0.005Ω 的导线流过 100A，两端电压差多少？72V 电池内阻 0.07Ω，正负极直接短路，电流大约多少？

### [ ] L2 功率和发热
- 功率 = 电压 × 电流；发热 = 电流² × 电阻
- 电流翻倍，同一根线的发热变 4 倍
- 能量 Wh = 功率 × 时间，续航怎么估
- 类比：水流过窄口时的摩擦损耗
- 检验题：0.005Ω 的导线过 100A 发热多少瓦？过 200A 呢？72V 30Ah 电池在 1000W 下大约能用多久？

### [ ] L3 串联和并联
- 串联：电压相加，电流相同；并联：电压相同，电流相加
- 电阻串联相加，并联变小
- 电池组 20S6P 是什么意思；组内阻怎么算
- 回路里每个接头、每段线、保险都是串联的电阻，压降一路累加
- 类比：水管首尾相接 vs 并排
- 检验题：单节 20mΩ 的 20S6P 电池组内阻多少？回路里有两个各 3mΩ 的接头和 2 米 10AWG 线，100A 时总压降多少？

### [ ] L4 电容
- 电容储存电荷，两端电压不能突变
- 给电容充电的电流取决于电压变化有多快
- RC 时间常数：充到差不多满要 5 × R × C
- 电调输入端的大电容：插电瞬间相当于短路，所以打火
- 类比：水塔，水位不能瞬间变高
- 检验题：72V 插到电调上为什么打火？预充电阻为什么能消除打火？2000µF 配 100Ω 大约多久充满？

### [ ] L5 电感
- 电感阻碍电流变化，电流不能突变
- 电流被突然切断时，电感会产生很高的电压尖峰
- 电机线圈是电感，长导线也有电感
- 类比：水管里的水有惯性，突然关阀门会产生水锤
- 检验题：带大电流时突然断开一个电感会怎样？为什么电调到电池的线不能太长？

### [ ] L6 电和磁
- 电流产生磁场；磁场对通电导体有力，这就是电机
- 导体在磁场里运动会产生电压，这就是发电机和反电动势
- KV 的物理意义：每伏电压对应的空载转速；转得越快，反电动势越高
- 类比：电机和发电机是同一个东西的两个方向
- 检验题：电调没通电时用手快速转电机，相线之间有没有电压？为什么电机转速越接近极速，电流越推不进去？

### [ ] L7 开关和 PWM
- MOSFET 当开关用：开着时电阻很小，关着时几乎不导电
- 每秒开关几万次，开的时间占比叫占空比；平均电压 = 电池电压 × 占空比
- 为什么不用可变电阻调速：电阻把多余的电压全变成热
- 开关的损耗在哪：导通损耗和切换瞬间的损耗
- 类比：快速开关水龙头控制平均流量
- 检验题：72V、占空比 50% 的平均电压？如果用电阻把 72V 降到 36V 给 50A 的负载，电阻上发热多少？

### [ ] L8 电压换电流
- 电调像一个可调的降压变速箱：两边功率大致相等
- 电机端电压低时，电机电流可以比电池电流大
- 电机线圈的电感把开关的脉冲电流抹平
- 为什么 VESC 要分别限制电机电流和电池电流
- 类比：自行车低档，脚上转得快、力气小，轮子转得慢、力气大
- 检验题：72V 电池出 20A，占空比 25%，电机侧电流大约多少？起步时为什么电池电流不大，电机电流却很大？

### [ ] L9 接地和参考点
- 电压永远是两点之间的差，「地」只是大家约定的参考点
- 信号要共地，否则接收方读不准
- 地线上有大电流时会有压降，参考点会「漂」
- 类比：两个人量身高，要站在同一块地板上
- 检验题：接收机地线松了，油门信号会怎样？为什么信号线不能和大电流线共用一段地线？

## 会发生什么（情景题库）

每题先猜，再听解释。括号里是需要先学完的课。

### 电路与发热（L1–L3）
- [ ] 扳手同时碰到电池正负极
- [ ] 一个接头接触不良，多了 5mΩ，100A 时会怎样
- [ ] 用 12AWG 细线代替 8AWG 粗线跑满功率
- [ ] 两组电压不同的电池直接并联在一起
- [ ] 一串电芯比其他的先没电，整组和 BMS 会怎样
- [ ] 保险丝的额定电压不够，熔断时会怎样

### 电容和电感（L4–L5）
- [ ] 72V 插头插进电调的那一瞬间
- [ ] 电调输入电容老化或鼓包
- [ ] 电池到电调的线加长到 2 米
- [ ] 带着负载直接拔掉主插头
- [ ] 用普通交流开关去断 72V 大电流

### 电机（L6）
- [ ] 电调没通电，用手快速转电机
- [ ] 电机三根相线断了一根
- [ ] 任意两根相线对调
- [ ] 桨被海草缠死，油门全开
- [ ] 桨突然出水

### 电调和 PWM（L7–L8）
- [ ] 满电时猛刹车
- [ ] 电机在刹车回收时 BMS 突然断开
- [ ] 占空比到 100% 还想再快
- [ ] 一个 MOSFET 击穿短路
- [ ] 电池电流上限设得很低，起步还有没有力

### 遥控和接地（L9）
- [ ] 接收机地线松了
- [ ] 两个 BEC 同时给接收机供电
- [ ] 接收机天线泡进海水
- [ ] 遥控器没电了
- [ ] 信号线和相线捆在一起走
